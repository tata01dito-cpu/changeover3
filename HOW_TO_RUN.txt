GitHub Pages (recommended)
1. Create a repo, upload ALL files in this folder to the repo ROOT (index.html must be at the top level, not inside another folder).
   Include the hidden file .nojekyll.
2. Settings > Pages > Source: "Deploy from a branch" > Branch: main, folder: / (root) > Save.
3. Open https://<username>.github.io/<repo>/ after ~1 minute.
4. If you see an old/blank page after re-uploading: hard refresh (Ctrl+Shift+R), or DevTools > Application > Storage > Clear site data (the service worker caches the old version).

Local test: do NOT double-click index.html (file:// blocks it). Run:
  python -m http.server 8000   then open http://localhost:8000
